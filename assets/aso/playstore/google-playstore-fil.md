# Full description (max 4000 characters)

Kontrolin ang iyong crypto nang lubusan. Ang NotWallet Crypto Self-Custody ay isang self-custody wallet para sa Solana — walang middlemen, walang restrictions.

Mga Feature:

• Ganap na Kontrol: Ikaw ang may-ari ng iyong mga private keys — hindi kami.
• Solana & SPL Tokens: Mabilis at murang transactions na direktang built sa Solana.
• Token Swap: Mag-exchange ng mga tokens agad sa loob ng app.
• Staking: Tumulong sa pag-secure ng network at kumita ng rewards.
• Web3 & DeFi: Kumonekta sa mga dApps, NFT marketplaces, at marami pang iba.
• Security: May biometric lock, local encryption, at zero data collection.

Bakit NotWallet Crypto Self-Custody?

Simple ang design. Mataas ang speed. Kumpletong kalayaan.
Ginawa para sa Solana — para sa mga taong pinahahalagahan ang kontrol, seguridad, at kalayaan.

Magsimula sa loob ng ilang segundo:

1. I-download ang app
2. Gumawa o mag-import ng iyong wallet
3. Magpadala, tumanggap, mag-stake, at tuklasin ang DeFi

Ang iyong crypto. Ang iyong keys.
